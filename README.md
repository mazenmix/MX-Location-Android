# MX Location Android

Independent Android edition of **MX Location** by MazenmiX.

## Current version
- Version: 1.1.0
- Version code: 5
- Package: `com.mazenmix.mxlocation`

## Features
- Smooth OpenStreetMap-based map UI
- Start / Change / Stop mock-location state controls
- Foreground mock-location service
- Smooth route interpolation with speed, bearing, altitude and accuracy variation
- GPX route import/export
- Saved location presets and history
- Joystick movement
- Background keep-alive controls
- Built-in GitHub update checker

## Update channel
The app checks `version.json` in this repository. When a higher version code is published, MX Location shows **Update Available** and can download the APK.

Android still requires the system package installer to approve an APK update unless the device is managed/rooted; MX Location does not bypass Android's installation security.

> This Android repository is separate from the iPhone/iOS MX Location project.
